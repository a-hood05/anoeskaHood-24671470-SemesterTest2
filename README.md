Web mapping application of the Hatfield farm

Tasks included:
1. Creating a web application using index.html, script.js and style.css
2. Adding a header and search bar
3. Adding a basemap
4. Adding building frootprints and other collected data for the UP Farm area of interest
5. Adding functionality that a popup appears when different feature are clicked and the attributes of that feature is displayed.
6. Adding a feature that allows the user to toggle between the different layers.

Folder structure:
This folder contains three files, index.html, style.css and script.js
The index.html contains the code that will be displayed as a web map. It contains two div sections. One section is the heading and searchbar while the other section is the map. Leaflet's css and script is also added, as well as the style.css and script.js The leaflet's css and style.css is added before the body.
The style.css file contains the style of the web dashboard. It dictates how the web dashboard will look like. It styles the top bar as well as showing the map. 
The script.js contains the code where the map is added with its basemap and different layers. This file also contains the popup function, layer control code for toggeling layers off and on again. Code that zooms to the layers is also added that makes it more convinient.  
The data folder contains code for all layers and are as javascript layers. This makes the code cleaner and easier to call when adding the javascript layer in the script.js folder.
